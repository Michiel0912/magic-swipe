# Magic Swipe v0.4.1 validation checklist

Target validation device: HONOR Magic8 Pro / MagicOS 10 / Android 16.

The candidate is a GO only if every required item below passes.

## Upgrade and updater policy

1. Install v0.4.1 over the existing v0.4.0 installation without uninstalling.
2. Confirm the header shows `v0.4.1`.
3. Confirm **Automatically check GitHub for updates** is OFF after the upgrade.
4. Turn the automatic-update switch ON.
5. Confirm an informed-consent dialog appears before any automatic check is allowed.
6. Confirm the dialog clearly says that GitHub APK downloads are outside F-Droid and bypass F-Droid build verification.
7. Choose **Keep disabled** and confirm the switch returns/remains OFF.
8. Turn the switch ON again, choose **Enable**, and confirm the switch stays ON.
9. Turn automatic checks OFF again and use **Check GitHub for updates now**. With public v0.4.0 as latest and local v0.4.1 installed, the expected result is that v0.4.1 is up to date.

## Existing UI

10. Confirm System default appearance works.
11. Confirm Light appearance works and remains readable.
12. Confirm Dark appearance works and remains readable.
13. Confirm changing appearance does not change gesture settings.

## Gesture regression checks

14. Confirm Back swipes work from the left edge extension.
15. Confirm Back swipes work from the right edge extension.
16. Open the software keyboard and confirm extreme edge keys such as A/Q/P/M respond immediately.
17. Confirm the Back extension does not cover the visible keyboard.
18. Confirm upper-corner toolbar controls, including three-dot menus, respond immediately with the default 80dp top exclusion.
19. Confirm the AccessibilityService remains enabled and operational after reopening Magic Swipe.

## GO / NO-GO

GO: all items 1–19 pass with no crash, no lost settings, and no new touch interception.

NO-GO: any automatic GitHub request occurs before explicit consent; consent can be bypassed; keyboard/top-corner regressions return; update installation becomes signature-incompatible; or the AccessibilityService gesture behavior changes unexpectedly.
