# Magic Swipe v0.4.0

Release date: 2026-08-17

## Highlights

- Added an optional built-in update checker using the public GitHub Releases API.
- Automatic checks run at most once every 24 hours when the settings screen is opened.
- Added a manual **Check for updates now** action.
- When a newer release exists, Magic Swipe shows the installed and available versions, release notes, and offers **Update** or **Later**.
- **Update** opens the official APK asset from the GitHub Release in the browser. Magic Swipe does not silently install APKs and does not request package-installer privileges.
- Added **System**, **Light**, and **Dark** appearance modes. System is the default.
- Added a dedicated light color palette.

## Privacy and permissions

v0.4.0 adds the Android `INTERNET` permission solely so the settings screen can query the public GitHub Releases API for updates. The AccessibilityService itself does not make network requests, retrieve window content, or inspect typed text.

## Compatibility

Validated on HONOR Magic8 Pro running MagicOS 10 / Android 16. Other Android devices remain expected or experimental until confirmed by real-device reports.

## Upgrade compatibility

Package ID remains `be.michiel.edgeback`, versionCode is 8, and direct GitHub APK releases must continue using the definitive Magic Swipe signing identity so they can upgrade an existing v0.3.x installation normally.
