# Magic Swipe v0.3.1

Released: 2026-08-16

## What changed

- Fixed delayed or difficult taps on keyboard keys near the extreme left and right screen edges.
- Magic Swipe now detects the visible software keyboard on Android 11+ and dynamically shortens its gesture overlays above the IME.
- Increased the default top exclusion from 28dp to 80dp so toolbar actions near the upper corners, such as three-dot menus, remain immediately tappable.
- Existing installations that still use the old 28dp top-exclusion default are migrated once to the new 80dp safe default; custom values are preserved.
- Back swipes remain active above the keyboard and return to their normal area after the keyboard closes.

## Validation

Validated on HONOR Magic8 Pro with MagicOS 10 / Android 16.

Confirmed during real-device testing:

- edge keyboard keys respond normally;
- long-press and rapid taps near the keyboard edges work normally;
- Back swipes work above the visible keyboard;
- Back swipes restore correctly after the keyboard closes;
- upper-corner toolbar actions, including three-dot menus, remain responsive with the 80dp top exclusion.
