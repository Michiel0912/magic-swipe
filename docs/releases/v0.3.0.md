## Validation

Validated on HONOR Magic8 Pro running MagicOS 10 / Android 16:

- App installs and launches successfully
- Left Back swipe works
- Right Back swipe works
- Test mode works
- Per-app language selection works
- Reboot persistence works
- AccessibilityService works as intended

The pre-release signing identity used by the older Edge Back Extender development build was unavailable, so existing development installs required a one-time uninstall before this definitive Magic Swipe signing identity was established. This happened before public distribution.

## Installation

Download `MagicSwipe-v0.3.0.apk` from the GitHub Release assets and install it on Android 8.0 or later. Enable Magic Swipe under Android Accessibility settings when prompted.

The app has no Internet permission, analytics, trackers, or screen-content retrieval.
