# Magic Swipe v0.4.1

This maintenance release makes the optional GitHub updater explicitly opt-in and prepares Magic Swipe for F-Droid submission.

## Changed

- Automatic GitHub update checks are disabled by default.
- Enabling automatic checks requires an informed-consent dialog.
- The consent dialog explains that GitHub APK downloads are outside F-Droid and bypass F-Droid's build verification.
- The update-available dialog repeats that warning before opening the official GitHub APK.
- Existing v0.4.0 installs are migrated to automatic checks disabled, so no automatic GitHub request happens until the user opts in again.
- Manual update checks remain available as an explicit user action.
- F-Droid metadata and the source-build helper are updated for versionCode 9.
- The build path is pinned to Android Build-Tools 36.0.0 for aapt2/D8/zipalign and Build-Tools 34.0.0 for reproducible-signature-compatible `apksigner` signing.

## Unchanged

- AccessibilityService gesture behavior is unchanged from v0.4.0.
- The AccessibilityService does not use the network or retrieve screen content.
- System / Light / Dark appearance modes remain available.

## Release validation

The final v0.4.1 APK was installed and tested successfully on HONOR Magic8 Pro / MagicOS 10 / Android 16.

- APK SHA-256: `056ecd7dbb3823aacbd7d14c1b585fad58696cdf25edb9a555f95fe4b0fdedb8`
- Signing certificate subject: `C=BE, O=Local, CN=Magic Swipe`
- Signing certificate SHA-256: `3B:8A:F9:D1:F2:D2:FF:AD:81:45:A3:4A:05:A8:05:BB:D4:C5:A5:08:32:72:0D:E2:76:25:3F:CD:B8:CA:AD:A6`
- All 12 non-signature APK entries match the pinned Linux F-Droid source build byte-for-byte, including entry order, compression and ZIP timestamps.
- Reapplying the final APK's v1/v2/v3 signing material to the Linux unsigned APK with the apksigcopier signing-copy algorithm reconstructs the final signed APK bit-for-bit with the same SHA-256 above.

This makes v0.4.1 suitable for the upstream-signed reproducible-build route once the GitHub release is published and F-Droid can fetch the public APK through `Binaries` for its final verification.
